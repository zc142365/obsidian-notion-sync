# Changelog

## 0.1.0

- Initial plugin release.
- Sync Obsidian Markdown notes to Notion pages.
- Preserve folder structure as nested Notion pages.
- Upload images and attachments with Notion file uploads.
- Convert wikilinks and local Markdown links to Notion page mentions.
- Add OAuth and manual token setup options.
- Add full sync, current note sync, force sync, and optional auto sync.
